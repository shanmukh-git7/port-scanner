# 🔍 Python Port Scanner

A simple and lightweight Python-based TCP Port Scanner that allows you to identify open ports on a target host. This tool demonstrates the basics of network reconnaissance, a foundational skill in cybersecurity and ethical hacking.

---

## ⚙️ Features

- ✅ Scans ports 1–1024 by default (can be modified)
- ✅ Accepts domain names or IP addresses
- ✅ Detects and displays open ports
- ✅ Uses built-in `socket` module (no dependencies)
- ✅ Displays scan duration for performance feedback

---

## 🛠️ Technologies Used

- Python 3
- `socket` (Standard Python library)
- `datetime` (for timing scans)
